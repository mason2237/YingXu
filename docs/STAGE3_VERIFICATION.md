# 第三阶段：匹配与审阅

日期：2026-10-21。当前 UI 为只读文件预览，所有审阅操作仅影响内存。

## 实现范围

- `yingxu/review.py` 保存一次扫描的候选字幕、关联、人工确认及跳过状态。初始主字幕沿用原核心一对一计划；显式、不同语言的字幕可自动关联到同一视频。`eng/en`、`chs/zh-cn` 等别名归为同一种语言；未知和重复语言供人工查看。
- 人工更换或添加字幕前检查归属与语言重复；可移除关联、确认低评分字幕、跳过及恢复。每次变化重新计算目标路径，继续使用现有冲突编号规则。人工指定保留真实评分与明显标记。
- 列表支持文本搜索、状态筛选与表头排序；代理模型将显示顺序映射回源视频，人工操作后按视频路径恢复选中。
- 详情提供候选名称、语言、评分、集数冲突提示和人工入口。拖拽单个文件夹可直接启动扫描。取消扫描会等待当前计算结束并丢弃结果，提示真实等待状态。
- 未修改 `yingxu/core.py` 或旧版 Tkinter 文件操作逻辑；未引入新依赖或网络处理。

## 行为边界

- 自动添加语言只用于有显式语言标签、不同语言且分数超过原匹配阈值的字幕。未知语言和重复语言交给用户审阅。
- 人工指定可覆盖集数冲突，但界面标注冲突与真实评分，并需显式确认才能从“需确认”转为“待整理”。
- 取消扫描不能中断正在运行的核心匹配计算；它防止完成的结果进入工作台。完成第四阶段前不执行整理，也不保存审阅历史。
