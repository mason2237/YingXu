## 文件安全与技术范围

- 未改 `core.py` / `operations.py`，无新增远程桥接权限、Token 或文件上传。
- 自动解压只写 UUID 缓存副本，单份自动关联也标为“需确认”；仍要确认匹配、最终预览、勾选执行及执行前冲突检查。
- 下载/导入忙时禁用不兼容操作，当前工作台任务结束后再自动准备；失败仅提示一次，允许手动重试。
- ZIP 沿用有界标准库读取；RAR/7z 用 Windows 自带 `System32/tar.exe`（本机 libarchive 3.8.8）向 stdout 流式读取，校验路径/类型后由原独占缓存写入器落盘，不直接展开包内路径。拒绝链接、特殊文件、重复路径；目录 256 KiB/200 项、单文件 8 MiB、每包展开 32 MiB/20 秒，每批 200 文件/128 MiB。
- 支持的系统 tar 版本不同可能导致格式失败，缺少解压器或格式不支持时提示改选 ZIP；不捆绑 Windows 系统文件。加密/分卷、ZIP64、嵌套包及 IDX/SUB 配对仍不支持。
- 自动开关只在主工作台集成窗口可用；独立开发入口没有审阅后端，保留下载暂存能力。
- Noto 字体来自 google/fonts 固定提交 `2894aab31764f10f29c421bdfd2340d3b382d384`，17,772,300 字节，SHA256 `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`。OFL 完整原文、Adobe 版权、来源和摘要随源码保存，运行包附完整许可证。未发现该字体与现有分发条款的直接冲突。
