# 6.3a 材质与帧率定向修订

日期：2026-10-22。基线：`acf65a1` / `stage6-3a-complete`。

用户反馈：烟雾像果冻，需要光特效、提高帧率、减薄顶部玻璃，并减少检查。本轮不扩展到 6.3b、真实文件接入或正式打包。

## 修改

- `list-mist.js`：移除整片旋转、浓雾填充和每行切片；改为细长、断续、向上飘散的纹理。光丝/局部光晕共用同一次绘制，仍在 DOM 文字下方。
- 原来每像素四组四层噪声，共 16 次；现为五次噪声，哈希不使用三角函数。画布尺寸从 0.8 倍变成 0.5 倍，像素量约减少 61%，文字分辨率不变。
- 调度由 32ms 时间门限改为累计 60Hz 预算，避免 144Hz 屏幕简单整除掉至 48Hz；悬停插值按经过时间计算。保留空闲停止、隐藏暂停、减少动态和普通材质回退代码。
- `upstream-effects.js` / `lens-runtime.js`：顶部单独较薄材质和低对比装饰画布，取消整条目录栏按压，子按钮继续使用原版手势。
- `lens-adapter.css` / `materials.css`：顶部内边距、亮边、整体光学对比和选中色面减弱；其他主操作按钮维持增强玻璃。
- 上游 Lens 源文件、Python 业务和原有文件权限均没有修改；没有新增依赖或原生接口。
