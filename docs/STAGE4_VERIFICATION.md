日期：2026-10-21。核心文件处理逻辑位于 `yingxu/operations.py`；Qt 对话框与线程分别位于 `yingxu/qt_ui/flow.py`、`apply_worker.py`。

## 文件安全

- 打开最终预览时冻结每份字幕的源与目标路径，并记录视频、字幕和目标目录的文件系统身份；对视频与字幕额外记录大小、修改及创建时间。预览前不移动媒体文件。
- 点击“确认并整理”前必须勾选已核对。后台任务先复核整批源/视频文件身份、目标是否已存在及目标目录，再开始第一个文件；每项执行前再次复核。状态变化时不重新分配文件名。
- Windows 同卷使用不覆盖现有目标的 `os.rename`；跨卷时独占创建目标、复制、复核源状态，再删除源文件。权限错误逐项记录。用户停止后保留已完成项，剩余项标为未执行。
- 跳过、未匹配和无需变更项目均计入结果，不进行文件改动。待确认的匹配必须先在详情中确认或跳过。
- 本地操作记录每次执行结束后写入 `%LOCALAPPDATA%/YingXu/history.jsonl`，逐份字幕记录源、目标、状态和错误；写入失败会在结果弹窗明确提示，并可导出本次结果。导出结果不覆盖已有文件。

## 已知边界

- 取消整理在当前文件完成后停止后续项；若操作已经开始，不能中途拆断单个文件的移动。
- 跨卷复制后的删除仍依赖文件系统权限，失败会报告，并尝试清理本次创建的目标。异常退出可能来不及写入完整批次记录，应重新扫描核对磁盘状态。
- 安全撤销未提供。可靠撤销需记录执行后的文件身份并检查原路径占用、目标被替换及部分失败；没有这些检查不应提供撤销按钮。
- 本阶段在当前 Windows 环境完成真实窗口与打包启动检查；其他 DPI 和干净系统验证留在阶段五。
