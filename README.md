# 映序

让每一份字幕，回到正确的位置。

拖入文件夹，核对匹配，确认整理。查找字幕、自动解压和已有字幕识别，都在这里完成。

[下载 Windows 版](https://github.com/mason2237/YingXu/releases/download/v0.10.0-rc.1/YingXu-0.10.0-rc.1-windows-x64.zip) · [查看本次更新](https://github.com/mason2237/YingXu/releases/tag/v0.10.0-rc.1)

适用于 Windows 11 x64 · 当前版本 0.10.0-rc.1（预发布版）

## 从一个文件夹开始

选择或拖入视频文件夹，映序会扫描视频和字幕，列出匹配结果。搜索、筛选、查看详情，轻松找到需要处理的文件。

## 缺少字幕，接着找

确认电影或剧集名称，批量查找合适的字幕。默认优先中英双语，也可以保存自己的语言偏好。

选择并下载后，映序会自动解压，准备好待确认的匹配。网站验证码和下载选择仍需你完成。

<img src="docs/images/online-subtitles-dark.png" width="1100" alt="映序在线字幕窗口">

## 已经有字幕，就少一步

视频内已有符合语言偏好的字幕，直接通过，无需再次下载或导出。识别结果可以手动调整；烧录在画面上的字幕暂不支持识别。

## 整理前，先看清

原来的名称、整理后的名称，放在一起核对。不确定的匹配可以更换或跳过，确认后才修改文件，已有文件不会被覆盖。

整理完成后，成功、跳过和异常一目了然，操作记录也会留在本机。目前尚不支持撤销。

## 看着舒服，用着顺手

明暗主题随你选择，也可跟随系统。玻璃质感与细腻的光影，配合更顺畅的滚动和按钮反馈。动效可以调整或关闭；支持 HDR 的设备可呈现更明亮的高光。

## 开始使用

1. 下载并完整解压，双击 `YingXu.exe`。请保留解压后的所有文件，无需额外安装环境。
2. 选择文件夹，核对匹配；缺少字幕时，可打开“在线字幕”查找。
3. 点击“预览变更”，确认名称和提示后再整理。

`Ctrl+F` 搜索 · `Ctrl+Enter` 预览 · 方向键选择文件

更新时请解压到新文件夹，旧版可继续保留。此前版本的设置与记录不会自动迁移。[查看使用说明](release/README.zh-CN.md)

## 使用须知

文件整理在本机完成，不上传视频。在线搜索只在你确认后发送片名；字幕是否适合当前片源，仍需核对。

当前为未签名的预发布版，已完成开发机上的主要流程验证，尚未在全新 Windows 环境测试。实际体验可能因设备和字幕网站状态有所不同。
