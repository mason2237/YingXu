## 渲染与 HDR

同一 300 项数据、1280×860、缩放 100%、系统 HDR 已开启，完整和适度简化配置分别连续交互 30 秒、重复三次。

完整版优化后页面更新约为：悬停 146–148fps，拖动 146–148fps，滚动 124–125fps。滚动 p95 约 14ms，仍高于原目标 11.2ms；没有证实持续性能目标已经通过。页面更新率不能代替实际显示帧率。

当前普通权限的 PresentMon ETW 采集被 Windows 拒绝，尚缺本轮独立实际呈现证据。未改用户组、系统权限配置或 HDR 开关。早期版本的呈现/HDR 证据仅对应当时构建，不冒充当前认证。

当前冻结 EXE 已重新验证 HDR：Windows Graphics Capture 返回 R16G16B16A16_FLOAT，三档校准高光线性采样分别为 2.99935、14.85677、75.91667，超过普通白点并逐档上升。它证明当前窗口存在扩展亮度输出，不是显示器物理峰值亮度测量，也不能替代帧率证据。
