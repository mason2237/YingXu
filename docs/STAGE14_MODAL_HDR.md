# 阶段十四：设置/快捷操作合成修复与 HDR 增强

日期：2026-10-24。版本：0.9.0-rc.7。本地候选，不自动上传。

## 用户问题与修复

用户在浏览设置和快捷操作时仍看到闪烁、界面消失，要求增加 HDR 特效。本次围绕这两个弹窗增加针对性检查，保留原文件服务与安全确认。

- 原合成检查中，网页 DOM/按钮/弹窗仍然响应，原生读回却只剩背景色；单独改 CSS 或换成 Qt layer 都没有使相同像素检查通过。保持直接绘制的 WebEngine 底层，并在弹窗期间主动更新 HDR 源纹理后，同一检查恢复了弹窗、文字和选中项。不是只凭 JS 无异常就认定画面正常。
- `desktop.qml` 保留可见网页底层，HDR shader 在源纹理临时缺失时输出透明，让底层保持可见。弹窗打开时按 16ms 请求源纹理更新，关闭后补 8 帧再停下；最小化/窗口隐藏/页面加载时不运行。没有常驻空闲动画循环。
- 新增 `CompositorHints`，只接收 `setOverlayActive(bool)`，提供只读布尔状态及通知；不接收文件、路径、URL 或命令，也不保存设置。只有原本受限本地网页注册该对象，远程字幕页没有获得 WebChannel。业务 `bridge` 与 `appearance` 方法权限不变。
- 本地工作台的 HTML 弹窗取消整页 `backdrop-filter`，用遮罩保留视觉层级；桌面弹窗开关直接完成，浏览器预览仍保留短动画。背景玻璃在弹窗期间冻结现有画面，不释放/隐藏 GPU 上下文；弹窗关闭后恢复。保留焦点、Esc、搜索和键盘操作。
- WebEngine 初始化前置到 QApplication 之前，仍使用已验证的 basic/D3D11 容器。一次备用线程探针卡住后已结束该测试；线程切换方案没有进入产物。

## HDR 特效

- 继续使用真实 D3D11/scRGB 浮点输出，当前 Windows HDR 开启、10-bit、SDR 白电平 240 nit；不改系统 HDR 开关。普通文字维持系统白电平。
- 柔和/增强的彩色高光增益由 15%/45% 调至 35%/120%；关闭档为零额外高光。着色器限制各通道不超过 scRGB 8.0，按 Windows 的 80 nit 标度对应 640 nit 信号上限；这是输出计算约束，不是显示器峰值实测。
- 增加四采样局部泛光，作用于亮蓝/青色强调；不增加 WebGL 上下文或额外离屏渲染目标。
- HDR 活跃时增强玻璃边缘、按钮悬停、输入焦点、快捷操作选中项、文件行选中边缘与任务进度亮端。只有真实 HDR 输出状态才启用这些标记；SDR 回退与减少动态偏好保持。
- 亮度增强保持关闭/柔和/增强三档；实际输出及高光说明显示在设置中。
