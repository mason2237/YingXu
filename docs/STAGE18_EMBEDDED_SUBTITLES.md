# 阶段十八：内嵌字幕自动通过与语言判断

日期：2026-10-25。版本：0.9.0-rc.11。本地候选，不自动上传。

## 已确认的需求

用户明确纠正：已有符合语言要求的内嵌字幕就直接通过，不需要导出。语言不对时继续原有外挂匹配或在线查找。本轮不提供字幕提取，不转码、不改写视频，不添加 OCR 或播放器。

## 实现

- 扫描时只读检查视频内字幕轨。默认中文（双语优先），可设置严格中英双语、简体、繁体、英语、日语、韩语或任意语言。
- 有符合要求的完整内嵌字幕，状态为“已符合”，详情说明“内嵌已满足”。不会分配外挂字幕，也不会加入默认在线搜索队列；预览/整理中计为无需变更。图片字幕也可按语言满足要求。
- 语言未知、标注冲突、读取失败或只有强制/片段/评论字幕时保留待处理。严格双语要求同一字幕轨标注中英双语，独立中文和英文两轨不冒称同时显示的双语字幕。任意语言明确包含未标注语言。
- 列表展示语言符合，详情显示轨道语言、格式、标题、默认/强制属性及判断依据。误标时可选择“仍需外挂字幕”，也可恢复采用已符合要求的内嵌字幕。
- 原来的视频/字幕文件、扫描/匹配/预览/确认和不覆盖机制保持。内嵌通过不生成文件、不下载外挂、不触发文件整理。
- 语言选项在扫描选项中保存；改变要求会使旧审阅及预览失效，重新扫描后应用。相同文件身份的轨道信息缓存在内存，最多 512 个条目，不落盘。

## 技术与许可

使用已审查的官方 pymediainfo 7.0.1 Windows wheel（MIT）及附带的 MediaInfoLib（BSD 2-clause 路径）。完整官方原文、第三方说明、wheel SHA256 和许可成员摘要保存在 licenses/ 与 SOURCES.json；未引入 FFmpeg 或执行第三方仓库脚本。

解析在固定的隐藏助手进程中进行；前端没有路径/命令执行接口。助手只从已打开的只读文件缓冲区读取，关闭引用文件和连续文件名探测，单视频 16 MiB 读取预算、3 秒软预算，主进程有 8 秒首次/4 秒后续硬超时并支持取消。每批复用助手，失败后丢弃解析器状态。Windows EXE 的无控制台模式通过继承的管道通信，不创建控制台窗口。

- 自生成的 16×16 VP8 MKV 和 MP4/tx3g 轨道样本已由实际 MediaInfo 读取，中文、英语、多轨、双语和含空格/中文文件名通过；不使用用户媒体。
- 26 项定向测试通过，覆盖语言规则、未知/冲突/强制字幕、图片轨、手动改判、不抢占外挂候选、无导出/无媒体改动、旧预览失效、缓存复用、取消、设置失败及参数白名单。
- 32 项原有核心/审阅/文件安全、33 项工作台/导入/协议/在线队列回归通过。语言规则细化后相关 10 项重验通过，共 91 项不同的单元/契约/回归用例；最终补验人工改判后的判断依据不再宣称“已通过”。
- 真实原生工作台 5 组交互通过：原生临时目录导入与扫描、语言状态和详情、无外挂动作及标题防注入、手动改判/恢复、实际语言控件和再次扫描；视频字节保持，没有新增字幕文件，无 Python/JS 错误。初次测试点击仍禁用的扫描选项按钮造成超时，补充等待 UI 恢复后通过，产品没有为通过而降低检查。
- 新 EXE 构建并实际启动/关闭通过：Qt 通信、15 本地资源、离线字体、36 玻璃操作/4 结构控件、1280×860 无横向溢出，无 JS/console error。输出仍报告 D3D11/scRGB/HDR 活跃、10-bit/240 nit 系统白电平；不是物理亮度认证。
- 实际无控制台 EXE 的解析助手在去除开发环境 PATH 后连续处理 4 个自生成 MKV/MP4 样本，通过继承管道返回正确结果；中文、英语、未知语言、独立中/英双轨判断通过，stderr 为空，没有导出或新增媒体文件。该检查证明随包 DLL 和窗口模式助手可用，不将其写成 EXE 全量媒体整理/视觉复验通过。
- 随包 MediaInfo DLL 与已审查官方 wheel 的记录摘要一致；pymediainfo MIT、MediaInfo BSD 原文和第三方说明随包保存，没有新增 Qt/QML 模块或修改上游 Lens 文件。

历史阶段十七的完整画面/动画复验超时尚未解决，本轮不把 DOM/业务检查冒称物理 HDR 或全面视觉认证；不重复无关的图形探针、实站下载或干净 Windows 测试。
