# 阶段十一：按深蓝玻璃参考统一桌面界面

日期：2026-10-24。基线 `cbe16db` / `0.9.0-rc.3` 保留，新本地候选 `0.9.0-rc.4`。

## 设计与实现

- 共用深蓝黑底、静态环境光、细蓝灰边框、通透面板和蓝色主操作；保留浅色主题。降低旧玻璃的强烈高光和浮雕，统一字号、图标与圆角，强调内容层级。
- 主工作台新增 `frontend/css/desktop-polish.css` 适配层，不修改原 Lens/Jelly 上游文件或重写组件。品牌、目录区、搜索筛选、空状态、详情占位及底部确认协调排版；保留虚拟列表、玻璃/拖动/雾气/减少动画设置。
- 在线窗口继续使用 Qt Widgets 承载受限网站视图，避免为了视觉再次迁移业务架构。`desktop_design.py` 集中静态背景、矢量图标、圆形三步引导、双行队列绘制与深浅主题；没有后台动画循环。
- 品牌栏提供真实工作台、同步主题、记录/设置入口；独立开发入口没有审阅后端时隐藏相关按钮。搜索和自动解压入口保留，结果区/队列/下载区分组清晰。
- 队列片名和季集分别显示，原文件名二行省略/悬停可读；鼠标/空格勾选保留原批量标记。清空会停止旧页面任务、清除内存队列并保留下载缓存，不删除文件或清除主工作台审阅。
- 宽窗口使用完整副标题与间距，窄/矮窗口收紧留白，940×700 可用。主题切换直接更新主工作台既有外观设置，网站页仍无 QWebChannel。
- Web 首帧流程先解除页面内部透明度，再等待两次绘制帧后移除原生遮罩；原主题/字体等待保留。

所有图标/背景为本项目矢量绘制或自有路径，未复制参考截图中的图像素材。使用已有 QtSvg（LGPL）与 Noto Sans SC（OFL），不新增 pip 包、不安装系统字体。原 PolyForm、MIT、OFL 和 Qt 许可文件保留。
