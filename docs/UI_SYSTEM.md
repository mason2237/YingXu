# 第二阶段界面骨架与设计系统

本文件前半部分记录原 Qt Widgets 设计基线；原 r2 的第五阶段细修按 r3 顺延至第八阶段。第六阶段 Web 设计参数与交互记录见下节。

## 第六阶段 Web 工作台设计系统

### 6.3b 工作台反馈与浮层（当前补充）

- Ctrl+K 打开同一工作台的快捷操作；16px 搜索、14px 动作行、明确选中层，快捷键右对齐。输入只筛选固定动作；中文组合输入时 Enter 不执行，禁用项不可运行。
- 通知以中性阅读面、细边框、状态图标与底部 2px 计时线呈现，160ms 进入/100ms 退出；指针、键盘焦点或页面隐藏会暂停。原生 popover top layer 解决通知被 dialog 遮挡；关闭候选后移回活动层。没有假撤销按钮。
- 已知总量用 Lens 原版进度工厂和实际 done/total，显示百分比与数量，DOM 轨道 8px；未知总量用 3px 不定进度线，不虚构百分比。减少动态时静态；加载结束立刻隐藏，不人为延长等待。
- 窄屏详情是原生 dialog，370px（较窄时 352px），边缘留 20px；保留同一详情 DOM 与真实操作按钮，短横向进入/退出，Tab 留在抽屉、Escape 还原。宽屏保持原并排布局。
- 浮层、状态提示和结果使用既有语义色；成功/跳过/异常数来自记录 DTO，分布条是 DOM，不增加 GPU 图表。空目录、搜索无结果、读取错误使用各自图标和可执行入口。
- 图标提示同时支持悬停和键盘聚焦；位置限制在窗口边界内，不占据点击区域。浮层打开暂停背景烟雾/粒子，减少叠加绘制；本次没有新增 WebGL 上下文。
- 来源与定向检查见 [STAGE63B_VERIFICATION.md](STAGE63B_VERIFICATION.md)。本阶段仍为显式示例；没有将加载动画或记录示例当成实际文件操作。

### 6.3a 气态列表 / 液态主操作（当前补充）

- 核心列表用连续向上飘散的稀薄雾丝，不按行切成色块，也不随指针整体旋转。悬停有局部光丝与光晕，选中仅轻度增强；单个 0.5 倍分辨率 WebGL2 画布位于虚拟列表与文字下方，字段仍为清晰 DOM。雾气 alpha 封顶，辅助文字按材质提高明暗对比度。
- 雾气是本项目程序化噪声视觉，未冒充参考仓库的 Lattice 点场。每像素五次噪声、无三角函数哈希；60Hz 目标按需绘制，实际受运行环境影响。停止操作后 0.45–1.8 秒停帧；减少动态时没有时间流动或指针光晕，保留静态背景与即时选中反馈。
- 顶部独立薄材质：增强 refraction .48 / blur .08 / dispersion .12，标准 .32 / .10 / .06；自绘背景降低对比，光学画布 opacity .45。工具栏不做整体按压形变、按钮仍有原版手势，内边距 8→4px；详情和预览按钮保持原增强材质。
- 详情两个按钮与底部预览按钮采用未修改的原版 Lens 渲染/手势。按组共享画布，画布只在真实按钮轮廓内显示；主按钮保留蓝色和白字，次按钮较浅，禁用时使用普通材质。稳定按钮节点保留焦点和事件，避免反复建立 WebGL 上下文。
- 气态列表与玻璃独立开关、外观偏好保存，兼容原设置；GPU 不可用恢复普通界面。其他弹窗和次要按钮的进一步统一留 6.3b。
- 原交付截图与动效见 [STAGE63A_VERIFICATION.md](STAGE63A_VERIFICATION.md)，最新修订截图与性能边界见 [STAGE63A_REFINEMENT.md](STAGE63A_REFINEMENT.md)；不提前接入文件整理或打包。

### 6.2 明暗主题（当前规范）

- 默认增强玻璃；顶部选择与外观面板共享 system/light/dark 偏好。跟随系统来自 Qt QStyleHints；不强行覆盖 OS 主题。
- 语义角色集中在 `tokens.css`：page/surface/ink/secondary/muted/line/accent/status/glass/focus/scrollbar 等。浅色阅读面白色、正文 `#202837`、品牌蓝 `#356de6`；深色页面 `#13161c`、阅读面 `#1b2029`、正文 `#e5eaf2`、品牌蓝 `#75a0ff`。
- 原版 Lens 文件不改：适配层更换自绘曲面背景，并用原版 ocean/grid 选择暗/浅 shader 染色；CSS 兼容材质同步配色。文字和文件名保持 DOM，不做像素反色。粒子使用当前语义色，声音默认关闭。
- 主题转换定向改编 Overture transition/focusPoint，180ms；不支持/隐藏/系统变化无触发点/减少动态时立即应用。转换可取消，切换保持筛选、选中、人工修改和弹窗状态。
- 固定 QSettings 键保存外观；DocumentCreation 引导、页面背景、窗口 palette 和 Windows DWM 标题栏在首次显示前同步，刷新/重新打开恢复偏好。测试使用临时 INI，不修改系统偏好。
- 实际 DOM 的 11 类文字采样：浅色最低 4.72:1、深色最低 5.32:1；未包含所有控件、GPU 背景或禁用文字，不代表完整无障碍认证。
- 900×620 / 1000×700 / 1280×860 布局、明暗弹窗和回退、原生标题栏截图已检查；不同真实 DPI/多显卡认证留第八阶段。详见 [STAGE62_VERIFICATION.md](STAGE62_VERIFICATION.md)。

### 6.1 原版 Lens 材质补充

目录栏、两个工具按钮与四个状态胶囊使用原版 `GlassRenderer` / `JellyController`，共七个光学表面，列表文字与详情仍用普通 DOM。默认增强参数 refraction .98 / blur .12 / dispersion .45；标准使用原版 Thick .90 / .24 / .65，可关闭。原色状态高光遵守上游支持的 green/gold 接口；应用主题按上节 6.2 适配。

工作台采用浅蓝曲面装饰背景；开发对照页提供高对比纹理和四种原版场景，便于观察实际折射。玻璃采样应用画布，不捕获任意 DOM 或桌面。材质关停使用普通实色表面、停止空闲绘制，少量画布缓存由 WebEngine 管理；页面销毁释放 GPU 对象与监听。

独立目录演示 18 类原版工厂，共享固定画布，仅当前控件可见；弹窗自己的画布位于顶层内部。帧计数用于自动检查，不显示在业务工作流。字体与布局保持下述骨架规范，剩余交互按 6.3 实施。详细来源、适配差异和实际证据见 [STAGE61_VERIFICATION.md](STAGE61_VERIFICATION.md)。

### 阶段 6 初始骨架参数（历史基线）

- 字体：Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI；不加载或分发远程字体。
- 中性背景 `#F5F7FA`、白色阅读面、深灰正文 `#202837`、品牌蓝 `#356DE6`。状态同时用文字、颜色及色点表示。
- 基础 15px；视频名称 15px、字幕/常用辅助 13px、搜索 14px；候选及变更名称 14px，完整路径 12px。语言缩写/快捷键/计数等紧凑元数据为 9–12px；不将它们用于主要操作说明。
- 默认 1280×860，最小 900×620；系统标题栏保留。列表 84px 双层行，评分/状态固定列，名称弹性省略并保留扩展名。详情全文换行、路径按需展开。
- 主体宽度不大于 1120px 时，详情用可关闭的右侧浮层；宽窗口并列显示，详情底部固定更换/确认/跳过操作，内容独立纵向滚动。
- 控件圆角 7px，主区域 11px，弹窗 14px；主按钮约 38–40px。4/8/12/16/20/24 间距，常规边框 1px；阴影只用于弹窗/浮层。
- 常规状态变化约 140ms；弹窗进入 170ms、退出 110ms；减少动画时取消过渡及粒子。按钮包含悬停/按下/禁用/焦点；弹窗关闭后返回触发点，触发点被重绘时返回列表。
- 玻璃仅在目录栏使用本地 WebGL2 shader：对程序生成的浅色装饰背景做边缘折射、高光和约 180ms 按压响应。列表/文件文字是独立 DOM，不进行折射。浮层采用普通阅读面和背景轻模糊，选中控件仅用色面/控件反馈。
- 粒子为最多 16 个点、约 650ms 的短反馈，在示例加载及“预览短反馈”时演示；结束、最小化、关闭效果、减少动画时取消绘制，不在空闲时持续运行。真实整理完成触发点留至第七阶段接入。
- WebGL 失败或上下文丢失回退为普通材质；外观偏好当前只在本次页面有效。第八阶段再验收真实系统 DPI、GPU 驱动及长期使用细节。

源码：`frontend/css/{tokens,components,workspace,lens-adapter}.css` 和 `frontend/js/components/`。初始基线证据见 [STAGE6_VERIFICATION.md](STAGE6_VERIFICATION.md)。

## 布局

- 系统标题栏；顶部显示品牌、目录选择、扫描和两个实际生效的扫描选项。
- 目录栏分为加粗目录名和完整路径两行，降低首次使用时的阅读负担。
- 主体为双行文件列表与右侧详情，通过 16px 分隔区域调整宽度。
- 视频与字幕同列，评分与状态固定列宽；主文件名列自动伸缩，不产生横向滚动。
- 默认 1240×840，最小 920×620。宽度小于 1100 时自动收起详情；按钮或双击列表可重新展开。
- 详情显示视频名、字幕名、目标名和评分依据；完整路径按需展开，文件名可选中复制。
- 长名称在列表中部省略，在详情中任意位置换行并完整展示；超长详情通过外层纵向滚动查看。
- 下方显示真实任务阶段和只读预览提示。文件数量未知时采用不定进度，不生成虚假百分比。

## 本阶段真实操作

- Ctrl+O 选择目录，F5 扫描；扫描中禁用会改变任务输入的控件。
- 上下键选择列表行，详情同步；Ctrl+I / 详情按钮开合；双击行展开详情。
- 切换扫描选项即清空旧计划，要求重新扫描，防止把旧目标路径当成新结果。
- 打开字幕/视频所在目录、复制目标名称、展开完整路径。
- 列表整行悬停；状态同时使用文字与色点；复制成功后临时显示勾选图标。
- 文件位置展开使用 160ms OutCubic 动画，可中途反向；读取 Windows 客户区动画设置，关闭系统动画时立即展开。环境变量 `YINGXU_REDUCED_MOTION=1` 也可关闭动画。
- 关闭正在扫描的窗口时等待任务结束，避免销毁仍在运行的 Qt 线程。

## 后续扩展

`VideoRecord.subtitles` 为不可变元组，当前将 core 的一对一结果适配成零项或一项，预留一对多展示结构。
模型通过 Qt 标准数据角色提供文件名、工具提示与辅助访问文本；第三阶段可接入代理模型做排序和筛选。
候选比较在详情区域扩展，多语言按关联字幕分组；第四阶段再接入变更预览与执行入口。
阶段二不提供无功能的搜索框、候选按钮或整理按钮。

## 第三阶段扩展

列表上方增加搜索和状态筛选，表头排序按显示顺序操作，但视频路径保持选中身份。详情底部固定“调整匹配与候选”入口，跳转到详情内候选区域；评分、语言、集数冲突和人工选择的状态一起展示。下拉框与输入框沿用共同边框、焦点色和控件高度。右侧详情空间不足时保持纵向滚动，候选名称可用完整文字确认。

## 第四阶段扩展

“预览变更”位于列表标题区，作为完成审阅后的主要入口。最终预览、结果与记录使用独立对话框：按视频分组，再逐份展示字幕与最终名称；选中项可查看完整源路径、目标路径和操作结果。用户必须在预览中勾选已核对才能执行。整理时底部显示实际已处理数量与停止剩余项操作；结束后可通过“查看结果”再次打开本次结果。
