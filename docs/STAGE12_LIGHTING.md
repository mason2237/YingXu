# 阶段十二：平整表头和可调光影

日期：2026-10-24。基线 `e79252b` / `0.9.0-rc.4` 保留，本地候选 `0.9.0-rc.5`。
用户指出匹配度表头仍呈异常凸起，并要求增加 HDR 效果及参考图光影。

## 改动

- 根因是通用 `GlassControls` 对所有按钮应用玻璃壳和弹簧，先前 CSS 覆盖仍被较高优先级规则覆盖。现在将表头排序与详情开关显式分为结构控件，不注册玻璃或弹簧，保留排序/点击/键盘焦点。主操作和筛选等继续使用原 Lens/Jelly。初始 42 个按钮中 38 个玻璃操作、4 个平整结构控件；不再以全按钮玻璃数量作为品质指标。
- 新 `frontend/css/lighting.css`：顶部/底部环境光、玻璃边缘细反光、面板暗部和柔影、主按钮局部光晕。普通显示器可见，未用全屏提亮/饱和滤镜，不模糊正文。
- 外观设置新增 `lighting` 枚举：`off` / `soft` / `enhanced`，默认增强，保存到既有外观设置，旧设置补默认值。Bootstrap 首帧即携带档位；受限接口只增加外观枚举，未新增方法或文件权限。
- Qt 在线窗口同步档位，静态绘制环境光、亮边与空状态局部柔光。只因光影档位变化时，Web 不重启原玻璃渲染器，避免无必要的 GL 更新。
- 所有效果均为 SDR 光影/色调设计，未申请 HDR 交换链、广色域或 PQ/scRGB 输出，不改变 Windows HDR 设置。界面和 README 如实标注，不以 PNG 效果冒称硬件 HDR 验收。
- 未修改扫描、匹配、下载/解压、预览确认、执行/不覆盖逻辑；没有新增依赖/第三方素材或修改上游原文件。
