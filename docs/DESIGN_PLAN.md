## 界面方向

中性灰白、深灰正文、少量品牌蓝。既有 Qt 基线为中文正文 11pt、辅助文字 10pt 起；Web 版正文约 15–16 CSS px、辅助 13–14px，实际 Windows 窗口中验收。
统一 4/8/12/16/24 间距、Web 版 6–10 圆角及约 36–40 逻辑像素控件高度；不直接混用 CSS px 与 Qt pt。
保留系统标题栏，统一悬停、按下、禁用、焦点等状态。
第六阶段加入局部液态玻璃（顶部工具栏、浮层、选中控件的轻折射/高光/按压反馈），文件列表保持清晰稳定。
粒子仅用于空状态或整理完成时的短暂反馈，低密度、可关闭；减少动画时自动简化，低性能设备可降级为普通材质。实际窗口验收后决定保留程度，第八阶段统一细修。

布局：紧凑品牌/目录/扫描工具栏 → 搜索与带数量的筛选 → 主列表和可伸缩详情 → 状态反馈。
取消大侧栏、装饰插画及大数字卡片；列表是主体。
列表每行分层展示视频与字幕，右侧显示状态及匹配依据；支持搜索、排序、键盘选择。
长名称保留有用的集数、语言、扩展名，详情可完整查看、复制。
详情支持人工换字幕、确认匹配、跳过与恢复；人工指定不显示为自动匹配 100%。
变更预览独立呈现源名称、最终名称、目录变化、冲突编号，确认后才执行。
预览后文件状态变化必须报告并要求重新检查，不悄悄生成不同目标。
