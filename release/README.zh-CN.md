# 使用映序

## 第一次打开

下载 Windows 运行包，完整解压到一个文件夹，双击 `YingXu.exe`。请保留解压后的所有文件，无需额外安装环境。

## 整理字幕

1. 选择或拖入视频文件夹，按需设置是否扫描子文件夹、是否移动字幕。
2. 查看匹配结果，确认、更换或跳过不确定的字幕。
3. 缺少字幕时，打开“在线字幕”，确认片名后查找并选择下载。
4. 下载完成后，映序会自动解压并准备匹配。回到工作台核对，再预览最终名称。
5. 勾选确认后整理，完成后查看结果与本地操作记录。

扫描和预览不会修改媒体，已有文件不会被覆盖。移除关联只改变本次匹配，不删除原文件。操作记录中可预览撤销；目标已被编辑或原位置被占用时会停止，避免丢失后来的修改。

## 更清楚地核对字幕

匹配详情会展示片名、年份、季集与版本线索。不确定或存在竞争的匹配会留给你确认；简繁、不同语言以及强制字幕、SDH 可以分别保留。

在字幕详情选择“检查字幕”，可以查看时间、空正文、重复及阅读速度等问题，并定位到原始行和片段；下载暂存也可查看检查结果。支持 SRT、ASS、SSA、VTT。编码无法确定时，先预览再选择。检查只读取文件，不自动修复或改编码；结果也不代表字幕一定属于该影片或已经同步。

## 视频内已有字幕

语言符合偏好时，直接通过，不导出或修改视频。可在扫描选项调整语言要求，在详情中手动改判。识别依赖片源标注，烧录在画面上的字幕暂不支持。

## 在线查找

默认优先字幕库，可切换备用来源。支持批量查找，语言偏好可以保存。字幕库和 SubHD 的受支持页面会自动执行普通下载步骤。网站要求验证或选择线路时，请在右侧完成。

点击候选旁的「下载字幕」。候选只显示在网站里时，打开字幕详情或下载页，然后点击「下载右侧页面的字幕」。下载过程中可以取消，任务中断后可以重新下载。支持常见字幕和压缩包，部分格式取决于 Windows 的支持情况。

下载后自动检查和解压。在「下载暂存」点击「加入工作台」，然后核对字幕和片源是否匹配。下载原包和关联信息保留。重启后先恢复并核对原目录与视频，再导入字幕。暂停的批量队列可在重新确认后继续。

可打开缓存、清除未导入且无引用的下载，或释放已导入但可回收的文件。活跃任务、审阅草稿、恢复和撤销仍引用的文件会被保护，超过 30 天按相同规则自动回收。暂存中显示「重试 / 核对续传」的任务会先核对下载对象。链接过期时，请回到网站重新下载。

## 补齐与调整

打开“字幕需求”，保存语言和用途，再检查本地字幕。已满足的变体不会默认重复查找；待核对表示已有线索，需确认归属、编码或质量。升级建议只加入待确认审阅，原字幕保留，新结果单独命名。

在视频详情的“增强识别”按需读取同名 NFO；可选头尾指纹仅用于字幕查询线索，不是整段视频的完整性证明。人工 IMDb 标识只用于当前作品。

在某份字幕下展开“调整字幕时间”。正数表示延后；负时间会拒绝，不静默剪掉对白。生成预览后勾选加入审阅，再使用工作台的最终预览与确认。原文件保留，整理结果仍可撤销；未采用的缓存结果可在重启后继续核对。参考字幕需主动选择，编码不确定时先核对。

音频模式先选择你信任的本机 FFmpeg，再主动填写音轨编号（首轨为 0）。映序会运行所选工具、核对完整视频的本地缓存身份，并分析该音轨，最多四小时；不提取字幕轨或上传媒体。只有一种已审查的本地分析引擎，明显错版本、静音、寡对白或分段不一致会拒绝，不能保证修复所有剪辑。FFmpeg 不随包分发，不自动下载模型。

文本辅助使用所选同语言参考和前六份文件名候选，展示三个窗口的本地短片段及前两项差距，不读取视频、不自动改配。

“清理音频分析缓存”只清理可重新生成的分析数据；“清除此未引用结果”保护审阅、恢复与撤销引用。不要手动删除整个本地数据目录。

## 外观与快捷键

可以选择浅色、深色或跟随系统，调整玻璃、光影和动效，也可以开启“减少动态”。HDR 高光需要显示器支持且 Windows 已开启 HDR，映序不会更改系统开关。

`Ctrl+F` 搜索 · `Ctrl+Enter` 预览 · 方向键选择 · `Enter` 查看详情

## 更新与记录

新版建议解压到新文件夹，先关闭旧版再启动。0.11 与 0.12 候选沿用本地数据目录；0.10 及更早旧架构的设置与记录不会自动迁移。本候选的设置、记录、恢复备份和下载缓存位于 `%LOCALAPPDATA%\YingXu\Desktop\`。升级前退出应用并备份整个目录，不能只复制数据库。识别和匹配规则更新后，旧草稿会保留人工关联并要求重新核对，旧确认不会自动生效；回退旧版请使用升级前的数据备份。

审阅选择保存为草稿，重启先核对文件再恢复；文件变化时请重新扫描。发生整理中断时，重新打开只会核对状态；请在操作记录查看恢复预览并明确确认。撤销同样需要预览确认。旧版记录不具备可靠身份信息，只能查看。记录可通过系统保存对话框导出为 JSON；已有导出文件不会被覆盖。

本版为未签名预发布版，已完成开发机主要流程验证，未在全新 Windows 环境测试。持续高刷新率目标尚未完成验收，不保证稳定 120fps。文件本地整理，不上传视频；主动搜索时仅发送片名。
